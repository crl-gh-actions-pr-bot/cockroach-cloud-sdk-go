# EditionType

## Enum
> A Continuum edition, which determines the capabilities a cluster's license grants. Editions are available only to organizations enrolled in Continuum, and a request naming an edition from an organization that is not enrolled is rejected. Editions and plans are separate axes, so a cluster reports one or the other, never both.   - STANDARD: The Standard edition grants the Standard capability set: row-level security, revision-history backups, changefeeds, and export.  - MISSION_CRITICAL: The Mission Critical edition grants the Standard capabilities plus physical cluster replication and logical data replication.

* `STANDARD` (value: `"STANDARD"`)

* `MISSION_CRITICAL` (value: `"MISSION_CRITICAL"`)
